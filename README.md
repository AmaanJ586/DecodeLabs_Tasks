# DecodeLabs Tasks

A collection of Python console applications developed during the Python Programming Virtual Internship at DecodeLabs (July – August 2026).

## Projects

| Program | Description |
|---|---|
| `General_Knowledge_Quiz.py` | Interactive quiz application on general knowledge topics |
| `Random_password_generator.py` | Random password generator |
| `expense_tracker.py` | Expense tracking application |
| `my_to_do_list.py` | Task management application |

## Requirements

- Python 3.x
- No external libraries required

## Usage

Run any program from the command line:

```
python <filename>.py
```

Example:

```
python expense_tracker.py
```

## Concepts Applied

- Control flow: conditionals and loops
- Functions and modular code structure
- Data structures: lists and dictionaries
- User input handling
- Console application design
